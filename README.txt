GILL FAMILY — 3D WEDDING INVITATION WEBSITE

HOW TO OPEN
1. Extract the ZIP file (do not try to run it from inside the ZIP).
2. Open Gill-Wedding-3D-Digital/index.html in Chrome, Edge or Safari.
3. Scroll down to open the animated invitation and turn the pages.

WHAT IS INCLUDED
- index.html: complete 3D scroll website
- assets/digital-envelope.webp: outer floral cover
- assets/digital-invitation.webp: invitation front page
- assets/digital-weddingday.webp: Anand Karaj and lunch page
- assets/digital-programme.webp: first programme page
- assets/digital-ceremonies.webp: second programme page
- assets/favicon.svg and share-preview.jpg: website branding

HOSTING
Upload the CONTENTS of the Gill-Wedding-3D-Digital folder
(index.html and assets directory together) to a static web host
like Netlify. Keep the assets folder alongside index.html.
External Google Fonts will require internet access. The card artwork,
3D animation, and event details are packaged locally.

NOTE
The website has not been published online. WhatsApp previews need a
public URL and absolute HTTPS Open Graph image URL configured after hosting.
